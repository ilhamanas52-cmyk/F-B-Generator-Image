# F&B Design Studio — Tahap 1 (Kerangka Next.js) Ini kerangka dasar hasil Tahap 1 migrasi dari Gemini Canvas ke Next.js/Vercel. **Belum berisi tab Brand/Menu/Promo/Konten 30 Hari/9 Feed** — itu akan dipindahkan di Tahap 2-6. ## Yang sudah ada di Tahap 1 ini - ✅ Login (Email/Password + Google Sign-In) - ✅ 2 halaman pendaftaran terpisah: `/daftar/single` dan `/daftar/reseller` (dipetakan ke 2 produk berbeda di Scalev) - ✅ Sistem "plan" (single/reseller/reseller_client) tersimpan di profil pengguna - ✅ Panel Admin Reseller (`/reseller`) — link undangan, daftar klien, white-label - ✅ Halaman terima undangan klien reseller (`/undangan/{resellerId}`) - ✅ Aturan keamanan Firestore (`firestore.rules`) — isolasi data antar pengguna ## Cara menjalankan di komputer Anda (development) 1. Install dependencies: ``` npm install ``` 2. Buat project Firebase baru di https://console.firebase.google.com (kalau belum punya) — aktifkan **Authentication** (Email/Password + Google) dan **Firestore Database**. 3. Salin `.env.local.example` jadi `.env.local`, isi dengan config Firebase Anda (Project Settings > General > Your apps). 4. Terapkan aturan keamanan: buka Firebase Console > Firestore > Rules, salin isi `firestore.rules` ke sana, klik Publish. 5. Jalankan: ``` npm run dev ``` Buka `http://localhost:3000`. ## Cara deploy ke Vercel 1. Push folder ini ke repository GitHub Anda. 2. Buka https://vercel.com, klik "Add New Project", pilih repo tadi. 3. Di pengaturan project Vercel, masuk ke **Settings > Environment Variables**, masukkan semua variabel yang ada di `.env.local.example` (dengan nilai asli Anda) — INI PENTING, jangan sampai terlewat, aplikasi tidak akan jalan tanpa ini. 4. Klik Deploy. ## Menyambungkan ke Scalev Di Scalev, untuk tiap produk yang dijual, atur "link pengiriman otomatis"-nya: - Produk **Paket Single** → `https://[domain-anda].vercel.app/daftar/single` - Produk **Paket Reseller** → `https://[domain-anda].vercel.app/daftar/reseller` ## Selanjutnya (Tahap 2-6) Tab-tab fitur (Brand, Menu, Promo, Konten 30 Hari, 9 Feed Konsisten) akan dipindahkan satu per satu dari kode Canvas, disambungkan ke struktur Firestore yang sama (`artifacts/{appId}/users/{uid}/appData/state`) supaya logikanya tetap konsisten dan teruji.
